神梦网络 HTML 加密功能
================================

项目名：html-encrypt

两个大类：
  前端版\         纯 HTML+JS，无需服务器，双击 index.html 即可用
       ├── index.html           加密界面（10 种算法，加密全在浏览器本地完成）
       ├── css\hxjmmw.css       样式
       └── js\hxjmmw.js         加密逻辑（无 PHP 依赖）
  后端版\         PHP 版（需要 PHP 环境），界面与引擎放在一起
       ├── index.php            PHP 版加密界面（10 种算法，POST 调后端引擎）
       ├── crypto_engine.php    加密引擎（接收 POST，返回 JSON 结果）
       ├── php\                 PHP 运行时（本地使用可放入 PHP 便携版，GitHub 仓库不含）
       └── 启动后端版.bat       一键启动（双击 → 起服务 → 自动开浏览器）
       （加密时会自动创建 out\ 文件夹，保存每次加密的未加密源码，属正常功能）

两种版本对比：
  ─ 前端版（前端版\index.html）：双击浏览器打开即可用，不依赖服务器，
    10 种算法（嵌套/位移/幻影/逆熵/异或乱码/异或数字/维度/叠加/AAA×2）。
  ─ 后端版（后端版\）：同样 10 种算法（与前端版功能对齐），需要 PHP 环境。
    本地使用：把 PHP 便携版放入 后端版\php\ 文件夹，双击 启动后端版.bat
    即可一键启动并自动打开浏览器（PHP 便携版可从 https://windows.php.net 下载）。
    部署到线上服务器时，把 index.php 和 crypto_engine.php 放同一目录即可。
    （注意：加密时会自动把未加密源码保存到同目录 out\ 文件夹，属正常功能）
  两版均已完成端到端验证：中文输入加密后，产物在浏览器执行可完整还原。
